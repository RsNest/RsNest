## 👋 Behind the profile

I'm a **DevOps / SRE engineer working across infrastructure and security**. I build and operate microservice platforms, automate delivery, and troubleshoot issues across Linux, Kubernetes, distributed services and networks.

I work through incidents by testing hypotheses, correlating signals and tracing dependencies — from the first symptom to the root cause. My focus is on reliable operations, useful observability and security that holds up in everyday work.

A **telecom / VoIP background** brings an extra perspective to protocol debugging, connectivity and integrations involving SIP, gRPC and identity services.
